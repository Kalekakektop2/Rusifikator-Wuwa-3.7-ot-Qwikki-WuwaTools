# О проекте

**Русификатор Wuthering Waves 3.7 от Qwikki / WuwaTools** переводит текст и интерфейс игры на русский язык. Сборка включает перевод и шрифт с поддержкой кириллицы. Озвучка персонажей и музыка остаются оригинальными.

Актуальная сборка рассчитана на версию игры **3.7.10**. Перевод обновляется отдельно от игры, поэтому новые строки, добавленные разработчиками после выхода сборки, могут временно отображаться на английском.

# Что входит в сборку

- **Текстовый PAK-файл** содержит переведённые строки и элементы интерфейса.
- **PAK-файл шрифта** добавляет поддержку кириллицы.
- **Файлы загрузчика для Windows** подключают PAK-файлы при запуске игры.

Для полного отображения перевода нужны оба PAK-файла: перевод и шрифт. Используйте файлы одной версии, не переименовывайте их и не смешивайте с файлами предыдущих сборок.

# Установка на Windows

## Через Wuthering Hub

Это рекомендуемый способ. Hub скачивает нужные файлы, размещает их в папке игры и проверяет наличие перед запуском.

1. **Закройте Wuthering Waves**, если игра уже запущена.
2. **Установите или откройте Wuthering Hub** и выберите установку русского перевода.
3. **Укажите папку игры**, если Hub не обнаружил её автоматически. Выбирайте папку, внутри которой лежат каталоги {b}Client{b} и {b}Engine{b}.  
   Для Steam обычно это {b}steamapps\common\Wuthering Waves{b}.
4. **Дождитесь окончания установки и проверки файлов.**
5. **Нажмите «Играть» в Wuthering Hub**, чтобы запустить игру с переводом.

Не выбирайте вложенную папку {b}Client{b}, {b}Binaries{b} или сам файл игры {b}Client-Win64-Shipping.exe{b} — указывайте корневую папку установки.

## Вручную

Используйте этот способ, только если устанавливаете файлы самостоятельно. Перед копированием закройте игру и лаунчер.

1. Найдите папку игры, внутри которой находится {b}Client{b}.
2. Скопируйте {b}winmm.dll{b} и {b}wuwaVietHoa.dll{b} в каталог:

```text
Client\Binaries\Win64\
```

   DLL должны лежать рядом с {b}Client-Win64-Shipping.exe{b}.

3. Скопируйте **оба PAK-файла** — перевод и шрифт — в каталог:

```text
Client\Content\Paks\~mods\
```

4. Если каталога {b}~mods{b} нет, создайте его с таким точным именем.
5. Уберите из {b}~mods{b} файлы других переводов и старые копии русификатора. Одновременная загрузка нескольких переводов может приводить к конфликту строк.
6. Запустите игру через Wuthering Hub и проверьте перевод.

# Установка на Android

Для телефона скачивается **отдельная Android-сборка**. Не используйте здесь Windows DLL и PAK-файлы.

1. Запустите Wuthering Waves хотя бы один раз, затем полностью закройте игру.
2. Скачайте Android-сборку по ссылке в разделе «Скачать». Распакуйте архив, если он загружен в ZIP.
3. Скопируйте оба PAK-файла из сборки — перевод и шрифт — в папку игры. Сначала проверьте основной путь:

```text
Android/data/com.kurogame.wutheringwaves.global/files/UE4Game/Client/Client/Saved/Paks/
```

4. Если папки {b}Paks{b} по этому адресу нет, проверьте альтернативный путь:

```text
Android/data/com.kurogame.wutheringwaves.global/files/UE4Game/Client/Client/Saved/Resources/Video/Paks/
```

5. Если нужной папки нет, создайте её. **Не заменяйте и не удаляйте штатные файлы игры.**
6. Полностью закройте игру и запустите её снова.

На Android 11 и новее система может скрывать {b}Android/data{b} от обычных файловых менеджеров. Если открыть папку не получается, передайте файлы через USB с компьютера либо воспользуйтесь файловым менеджером с поддержкой этой папки.

# Настройки языка и совместимость

- В настройках Wuthering Waves выберите **English** как язык текста.
- Перевод меняет текстовые ресурсы, но не озвучку.
- После обновления игры может понадобиться новая версия русификатора.
- Это неофициальный фанатский проект; он не связан с Kuro Games.

# Если перевод не появился

Проверьте эти пункты по порядку:

1. **Язык текста — English.** После смены языка полностью перезапустите игру.
2. **Установлены оба PAK-файла.** Один содержит перевод, второй — шрифт. На Android используйте файлы именно из Android-сборки.
3. **Файлы лежат в нужных каталогах.** DLL находятся рядом с {b}Client-Win64-Shipping.exe{b}; PAK-файлы — в {b}Client\Content\Paks\~mods\{b}.
4. **В папке нет старых копий и других переводов.** Оставьте только актуальный комплект.
5. **Имена файлов не менялись.** Не добавляйте и не удаляйте расширения {b}.pak{b}.
6. **Сборка соответствует версии игры.** После патча игры проверьте, доступно ли обновление русификатора.

Сообщение {b}Hooked successfully{b} подтверждает, что DLL загрузчика подключилась. Оно само по себе не подтверждает, что игра нашла и применила нужные PAK-файлы.

Если проблема сохраняется, напишите в [Telegram Wuwa News](https://t.me/WuwaNewss). Укажите платформу, версию игры и способ установки; приложите снимок экрана или текст ошибки. Не отправляйте пароли, токены и другие данные аккаунта.
